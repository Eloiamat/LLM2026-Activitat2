Activitat 2

Introducció als llenguatges de marques

Els llenguatges de marques permeten estructurar i organitzar la informació d'un document perquè pugui ser interpretada correctament per un navegador o per altres aplicacions.

Un dels llenguatges de marques més utilitzats en el desenvolupament web és HTML, que s'encarrega principalment de definir l'estructura i el contingut d'una pàgina web.

Què és el HTML

HTML és un llenguatge de marcatge que s'utilitza per crear i estructurar el contingut de les pàgines web.

Amb HTML podem afegir títols, paràgrafs, imatges, enllaços, llistes i altres elements a una pàgina web.

HTML utilitza etiquetes per indicar al navegador quin tipus d'element estem creant. Per exemple, podem utilitzar l'etiqueta `h1` per crear un títol principal i l'etiqueta `p` per crear un paràgraf. També podem utilitzar HTML per afegir enllaços a altres pàgines web, inserir imatges i organitzar la informació de manera estructurada.

Què és CSS?

CSS és un llenguatge que permet definir l'estil i l'aparença d'una pàgina web.

Amb CSS podem modificar els colors, les fonts, les mides, els marges i la distribució dels elements.
